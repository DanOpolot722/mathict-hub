How this admin panel works

This site is a static site (HTML/CSS/JS) so it can be hosted for free on GitHub Pages, which means there's no database on a server.

  • Announcements you post here are saved in this browser's local storage, so they show up on the Announcements page when viewed from this same browser/device.
  • Resource links, folder IDs, WhatsApp number, and Drive email are edited directly in js/config.js — that keeps them consistent for every visitor, on every device.
  • For a fully multi-device admin experience (post from your phone, visible to everyone), connect a small backend or headless CMS — the js/admin.js file has notes on where to plug that in.
